# 角色 1:系统管理员 (admin)

## 您能看到的菜单
系统管理 / 用户管理 / 角色权限 / 账套管理 / 操作日志 / 数据备份 / 所有业务模块(全权限)

## 您的工作
1. **初始化** — 新建账套、设置启用期间、灌科目表
2. **用户管理** — 新建/停用用户、分配角色和可见账套、重置密码
3. **角色权限** — 调整角色权限勾选、新建自定义角色
4. **账套管理** — 改公司名、税号、地址、法人、启停账套、删除空账套
5. **审计** — 操作日志查询(谁在什么时候改了啥)
6. **备份** — 一键备份数据库,下载 .dump 文件

## 您不能做的事
- 录凭证(走专业会计,职责分离)
- 审核凭证(同上)
- 报销(不参与日常业务)

## 账套管理实战

**改公司信息**:`账套管理` → 当前账套卡 → 改名称/税号/地址/法人 → `保存` → 看到"企业信息已保存"。

**新建账套**:`账套管理` → `我的账套` 表格上方 → `新建账套` → 填名称、税号、启用年/月 → `保存` → 新账套进入"未启用"状态。

**启用账套**:`启用前必须先录入期初`:财务模块 → `期初建账` → 填末级科目的期初借/贷方 → `试算平衡`(借贷相等)→ 回到账套管理 → 启停按钮 → 二次确认 → 启用成功。

**停用账套**:`账套管理` → 启停按钮 → 二次确认 → 期间解锁,可改公司信息和启用期间。

**删除账套**:**仅超管可删,且必须先停用 + 无任何业务数据**(无凭证/科目/往来)。系统会自动校验,有数据会拒绝。

> 详情见 `/help` 页面 → 账套管理章节。

# 角色 2:财务主管 (cfo)

## 您能看到的菜单
经营看板 / 凭证审核 / 期末处理 / 全部报表 / 资金管理 / 应收应付 / 发票 / 资产 / 报销审批(总经理节点)

## 您的工作
1. **审核凭证** — `凭证管理` → 待审 → `审核记账`(注意制单人和审核人不能是同一个人)
2. **反审核** — 期间未结账 + 该凭证未被下游单据引用 → 才能反审
3. **结转损益** — 每月末一次,自动生成"转"字凭证
4. **计提折旧** — 每月末一次,自动对全部在用资产
5. **期末结账** — 四项闸门全过才能关期间
6. **复核报表** — 资产负债表(任何时刻都应平衡)、利润表(本期+年累计)

## 审核凭证

```
1. 凭证管理 → 状态筛"待审"
2. 点"审核记账" → 系统校验:
   - 借贷平衡(必须)
   - 期间开放(必须)
   - 制单人 ≠ 审核人(强制 — 内控)
3. 成功 → 状态变"已记账"
```

**遇到拒绝**:
- "制单人与审核人相同" → 换其他财务账号
- "借贷不平" → 让制单人改
- "期间已结账" → 反结账(下期无凭证时)

## 月末固定动作(顺序执行)

```
1. 结转损益 → 自动按科目+辅助维度分组,生成"转"字凭证
2. 计提折旧 → 平均年限法,当月新增不提,提足自停
3. 期末处理 → 检查清单 4 项(上期已结/无待审/损益已转/试算平衡)
4. 执行结账 → 期间关闭
```

## 红冲(发现已记账凭证做错)

```
1. 凭证列表 → 找到那张凭证
2. 点"红冲" → 选日期(必须在同一启用期间)
3. 系统生成一张**反向**新凭证(借贷互反)
4. 新凭证正常提交+审核
5. 原凭证保留(审计轨迹完整)
```

> **注意**:同一张凭证只能被红冲一次。

## 报表解读

| 报表 | 怎么看 |
|---|---|
| 资产负债表 | 任何时刻都应平衡徽标(绿);"未分配利润"自动含未结转损益 |
| 利润表 | 本期 = 所选月份;年累计 = 当年 1 月至今(不含结转凭证,反映真实收入费用) |
| 科目余额表 | 借/贷六列(期初/本期发生/期末)+ 年累计发生;底部合计借贷相等绿标识 |
| 明细账 | 选末级科目 + 月份区间,期初行 + 逐笔 + 本期合计 + 期末 |

# 角色 3:会计 (zhangsan)

## 您能看到的菜单
经营看板 / 凭证录入 / 凭证查询(本人录的) / 应收应付 / 发票 / 资产 / 期末折旧计提

## 您的工作
1. **录凭证** — `凭证管理` → `新增`
2. **核销** — 应收单 / 收款单多对多勾兑
3. **发票登记** — 进项/销项,可批量导入 CSV
4. **资产卡片** — 录入固定资产
5. **折旧计提** — 月末计提(财务主管复核)

## 录凭证的技巧

```
1. 凭证管理 → 新增
2. 选日期(必须在启用期间内,否则拒绝)
3. 凭证字(收/付/转),序号自动
4. 选科目:
   - 只能选末级科目(带下拉标记)
   - 输编码或名称搜索
   - 带 ⚠ 标记必须填辅助核算(部门/项目/往来单位)
   - 1002 开头自动出结算方式 + 票据号
5. 输金额:借或贷一边,自动清另一边
6. 实时显示借方合计、贷方合计、差额(必须 = 0)
7. 保存 = 草稿;点"提交" = 待审
```

**辅助核算快速记**:
- 应收账款(1122)→ 选往来单位
- 管理费用-办公费(660102)→ 选部门
- 制造费用(5101)→ 选部门 + 项目
- 主营业务收入(6001)→ 选部门 + 往来单位

**保存按钮是灰的?** 借贷不平 / 末级 / 辅助核算必填,看底部差额提示。

## 红冲(发现已记账凭证做错)

**您不能自己红冲** — 请联系 cfo 走流程,保证审计轨迹。

## 核销(应收款)

```
1. 应收应付 → 选"应收单"标签
2. 新建应收单(客户 + 金额 + 发票号)
3. 收款时新建"收款单"(关联客户)
4. 点"核销" → 选应收单 + 收款单 + 核销金额
5. 双方"未核销余额"自动减少
```

**一收多欠**:一个客户欠 N 笔,可分多次核销,每次核销单独选。

# 角色 4:出纳 (lisi)

## 您能看到的菜单
经营看板 / 资金管理 / 银行对账 / 报销付款(已审批通过的)

## 您的工作
1. **资金日记账查询** — 现金(1001)/银行(1002)科目的已记账分录
2. **对账** — 导入网银对账单,自动勾兑(±3 天)
3. **付款** — 报销单状态"待付款" → 您执行付款 → 自动生成付款凭证
4. **账户管理** — 新增银行账户(绑定 1002 科目)

## 银行对账流程

```
1. 资金管理 → 新增账户(选 1002 末级科目)
2. 资金管理 → 导入对账单 → 上传网银导出的 CSV(日期,金额,摘要)
3. 点"自动勾兑" → 系统按金额 + ±3 天匹配
4. 手工调整未勾对的项
5. 看"余额调节表":企业账面余额 vs 银行对账单余额 + 未达账项
```

**勾不上怎么办**:
- 对方摘要记错
- 跨月(不在 ±3 天)
- 金额不等(单位错)
→ 走"手工勾兑"指定对应账面记录

## 报销付款

```
1. 报销审批 → 状态筛"待付款"
2. 点"付款" → 选资金账户
3. 系统自动生成付款凭证(借:其他应付款 / 贷:银行存款)
4. 报销单状态变"已付款"
```

# 角色 5:员工 (wangwu)

## 您能看到的菜单
我的报销

## 您的工作
只有一件事:报销

```
1. 我的报销 → 新建报销
2. 填标题(例如"8月差旅费")
3. 加明细行:
   - 费用类型(办公/差旅/招待...)
   - 发生日期
   - 金额
   - 发票张数
4. 上传发票照片(支持 jpg/png/pdf,≤10MB)
5. 提交 → 进入审批流
6. 实时看状态:草稿 → 待部门审批 → (≥5000 元)待总经理 → 待财务 → 待付款 → 已付款
```

**驳回后**:状态变"驳回",您可以改后再次提交(财务会写意见)

**撤回**:财务复核前任何时候可以点"撤回"回到草稿,改完再提交

## 我的状态

| 状态 | 含义 | 我能做什么 |
|---|---|---|
| 草稿 | 还没提交 | 改 / 删 / 提交 |
| 待部门审批 | 部门领导在看 | 撤回 |
| 待总经理审批 | 总经理在看(≥5000 元) | 撤回 |
| 待财务复核 | 财务在看 | 撤回 |
| 待付款 | 出纳付款中 | 等 |
| 已付款 | 完成 | 看 |
| 驳回 | 被拒了 | 看意见 → 改 → 再提交 |
| 撤回 | 自己撤了 | 改 → 再提交 |

# 通用:每个角色都会用

## 改密码

`个人中心`(右上角头像)→ `修改密码` → 输旧 + 新 → 保存 → 重新登录。

## 切账套

`右上角下拉` → 选目标账套 → `切换` → 整个系统切换数据(数据完全隔离)。

## 导出 Excel

任意列表页 → `导出` 按钮(右上)→ 浏览器下载 .xlsx → 双击打开。

## 健康检查

`系统管理 → 健康检查`(或 `/system/health` 直接访问)→ 一键 ping 所有关键接口 + 给出排查建议。**出错时第一件事**。

## 常见问题 FAQ

**Q:凭证保存按钮是灰的?**
A:借贷不平 / 末级 / 辅助核算必填。看底部差额提示。

**Q:审核报"制单人与审核人相同"?**
A:内控规则。换其他财务账号。

**Q:结账按钮报错?**
A:看检查清单哪一项 ✗:通常是还有草稿/待审,或没结转损益。

**Q:资产负债表不平?**
A:几乎不可能。若看到,立即截图报告 — 这是 P0 bug。

**Q:反审核/反结账点不动?**
A:反审核要期间未结 + 无下游引用;反结账要下期无凭证。

**Q:手机上能用吗?**
A:能。浏览器直接访问,界面自适应(底部 TabBar)。

**Q:Excel 打不开?**
A:用 Mac/Excel 2016+ / WPS。如真打不开,联系 admin 看 `/system/health` 验证。

# 2026-10 新功能操作指南

## 现金流量表(财务主管 / 总经理)

`报表中心 → 财务报表 → 现金流量表`:选择会计期间即出表。系统按「对方科目法」自动归集
三大活动现金流(经营/投资/筹资),页脚实时勾稽「净增加额 = 期末现金 − 期初现金」。
未自动归集的对方科目会列入页面下方「未分类明细」(已计入「其他经营」行),补科目映射前请人工核对。
支持导出 Excel 与打印。

## 工资核算(财务主管 / 会计)

`业务核算 → 工资核算`:
1. 选年月 → 点「加载/初始化」,按在册员工生成工资行;
2. 行内填应发/代扣社保/代扣个税,实发自动计算,底部实时合计;
3. 「保存工资单」→「计提工资」:自动生成凭证(借 管理费用-工资,按员工部门拆分;贷 应付职工薪酬),提交待审;
4. 审核记账后回工资页点「发放工资」:生成凭证(借 应付职工薪酬;贷 银行存款 实发 + 其他应付款 代扣,未缴暂挂)。

注意:计提人不能自己审核(制审分离);**红冲工资凭证会自动把批次退回上一步**,调整后可重新计提/发放。

## 增值税申报测算(财务主管)

`发票台账 → 申报测算`:选年度与季度,自动按税率分组汇总销项/进项,并给出双口径测算
(一般纳税人:销项−可抵扣进项;小规模:不含税销售额×征收率)。可导出三 Sheet Excel。
**仅供申报前测算参考,实际申报以电子税务局口径为准。**

## 凭证 Excel 批量导入(会计)

`凭证列表 → 批量导入`:先「下载导入模板」(列:日期|摘要|科目编码|借方金额|贷方金额|往来单位|部门)。
规则:科目须为末级编码;日期相同的连续行合为一张凭证;空日期沿用上一行;金额仅填一侧;
往来单位/部门按档案名称精确匹配。导入生成草稿,失败行会列出原因(已导入的不受影响)。

## 凭证模板与复制(会计)

- **复制**:凭证列表行内「复制」→ 新凭证页自动带入全部分录,确认后保存;
- **模板**:录入页「存为模板」;下次点「应用模板」一键带入;
- **摘要联想**:摘要框输入时自动提示本账套历史摘要(按使用频次排序)。

## AI 智能体(管理员配置,所有角色受益)

按 `docs/MCP-GUIDE.md` 配置 Claude Desktop / Cursor 后,智能体可以直接查账、出报表、记草稿凭证
(「这个月利润多少」「帮我记一笔:综合部报销办公费 200,现金支付」)。
AI 记的凭证一律是草稿,须人工审核才入账;建议配置专用最小权限账号。
