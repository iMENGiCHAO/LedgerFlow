## 6. 本轮开发发现并修复的缺陷

| 缺陷 | 根因 | 修复 |
| --- | --- | --- |
| 资产负债表不平衡(差 139,600) | 未分配利润行未包含当期未结转损益 | 公式引擎新增伪科目 `@pl`(损益类自然余额净额)并入留存收益行 |
| 利润表默认取到空期间(2027-12) | resolveSeq 取最大期间而非当前日历月 | 改为「不晚于当前日历月的最晚开启期间」 |
| 利润表本期=年累计 | 控制器把起点固定在 1 月 | 本期=单期间;fromMonth 参数可选提前起点 |
| 年累计收入被结转凭证抵减 | 发生额聚合含 sourceType=4 结转凭证 | IS 口径排除结转凭证 |
| 明细账 SQL 报错 line_no 不存在 | Prisma 映射列名为 "lineNo" | 修正引号列名 |
| 多列表接口数值筛选失效(periodId/status/type 等) | query 参数为字符串直接进 Prisma Int 过滤 | 服务层统一 Number() 强转 |
| 无发生额科目导致余额表 500 | balMap 缺项取值 undefined | 补零余额兜底 |
| 结账检查对纯损益科目 500 | 同上 | 同上 |
| 结转损益报「需要选择部门」 | 冲销行丢失辅助核算维度 | 按「科目+部门/往来/项目」分组生成冲销分录,维度随行携带 |
| 结转损益借贷不平(方向写反) | 尾差调整逻辑符号错误 | 净额方向修正:借方富余贷记本年利润 |
| 红冲可重复执行 | 红冲关联字段 redForVoucherId 未落库 | create 支持 redForVoucherId 并写入 |
| 报销付款生成凭证失败「非末级科目」 | 费用类型映射到父级 5602 | 映射改为 560201/560202/560203 等明细科目 |
| 经营看板显示空期间(2026-08) | 默认取当前日历月 | 改取「最近有记账数据的期间」,无数据回退当前期间 |
| 备份失败 pg_dump 版本不匹配(16 vs 17) | PATH 中 pg_dump 低于服务器版本;SHOW server_version 列名无别名 | 自动探测 `/usr/local/opt/postgresql@<major>/bin/pg_dump`;列名按实际解析 |

## 7. 安全与内控验证要点

- bcrypt 密码存储、JWT 双令牌、错误密码拒绝;
- 权限矩阵生效:员工无凭证权限(403)、出纳无审核权、制单人不能 self-approve(R7);
- 危险操作全部二次确认(前端)+ 服务端状态机硬校验双层防护;
- 敏感操作 before/after 日志留痕(21 条可查);
- 备份文件服务端生成、blob 带 Token 鉴权下载。
